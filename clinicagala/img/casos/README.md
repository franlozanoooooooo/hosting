Sustituye el `.jpg` correspondiente por **2 fotos** (antes y después, **mismo
encuadre**), proporción horizontal ~16:10, mínimo 1000 px de ancho.
Si falta algún archivo, se muestra la ilustración demo (`caso-demo-*.svg`).
